One sentence about the best advice ever received: a voice teacher stopping a singer mid-phrase to say the silence is the note you earn — a finger still tapping that rest before every first note.

## Run it

```sh
node main.ts
```

The program writes the sentence to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
